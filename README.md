# LPAWEB - Linguagem de Programação para Aplicativos Web 🌐

Este repositório contém os exercícios e projetos práticos desenvolvidos por mim durante as aulas do curso técnico integrado. O foco das atividades é o aprendizado de arquitetura web, lógica de programação aplicada e desenvolvimento de sistemas para internet.

---

### 🇺🇸 Project Overview (English)
This repository hosts the practical exercises and web applications developed during my Technical High School program in Computer Science. It showcases my journey in web development, tracking my evolution from basic scripting to structural web logic.
