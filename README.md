# LPAWEB - Linguagem de Programação para Aplicativos Web 🌐

Este repositório contém os exercícios e projetos práticos desenvolvidos por mim durante as aulas do curso técnico integrado. O foco das atividades é o aprendizado de arquitetura web, lógica de programação aplicada e desenvolvimento de sistemas para internet.

---

### 🇺🇸 Project Overview (English)
This repository hosts the practical exercises and web applications developed during my Technical High School program in Computer Science. It showcases my journey in web development, tracking my evolution from basic scripting to structural web logic.

### 📁 Organização do Repositório / Repository Organization

**br** O código está dividido por períodos letivos para demonstrar a evolução do aprendizado:
*   `1trim/`: Primeiros contatos com a estrutura web e sintaxe lógica inicial.
*   `2trim/`: Exercícios avançados semanais, manipulação de elementos e integração de páginas.
*   `3trim/`: Exercícios de fixação diários, manipulação de elementos e introdução ao JavaScript no desenvolvimento web.

**🇺🇸** The code is divided by school terms to show my learning evolution:

*   `1trim/`: First contact with web structure and basic logic syntax.
*   `2trim/`: Advanced weekly exercises, element manipulation and page integration.
*   `3trim/`: Daily practicing exercises, element manipulation, and an introduction to JavaScript for the web.
